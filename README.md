## Open locally

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
pip install numpy jupyter
jupyter notebook
```

Open the notebook you want to study and run its cells in order.

## Scope

This is a fundamentals notebook repository, not an application or a data-engineering pipeline. It supports my Python foundations; project repositories demonstrate more applied ETL and SQL work.
